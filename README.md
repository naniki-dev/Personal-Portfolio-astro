## About

A rebuild of my original portfolio (plain HTML/CSS/JS) using Astro's component-based architecture, built as a hands-on way to learn how modern frontend frameworks work.

## Tech stack

- [Astro](https://astro.build)
- TypeScript
- Vanilla CSS
- [Typewriter Effect](https://github.com/tameemsafi/typewriterjs) for the landing animation
- [Tabler Icons](https://tabler.io/icons)
